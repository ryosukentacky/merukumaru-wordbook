003｜たむろ（屯する）

品詞：動詞｜意味：複数人が、ある場所に集まって、しばらくその場にとどまること

「先輩、"たむろ"という言葉を聞いたことがありますか？」
「"たむろ"とは、複数人が、ある場所に集まって、しばらくその場にとどまることです。」
「例えば、コンビニの前で友達と話し込んだり、駅前で待ち合わせをして集まったり…そんな様子が"たむろ"なんです。」
「ところで先輩、"たむろ"は漢字で書くと"屯する"になります。"屯"には、人が集まるという意味があるんですよ。」

A｜要点：まず意味をつかみましょう

「先輩、"たむろ"とは、複数人が、ある場所に集まり、しばらくその場にとどまることを指す言葉です。」
「単に人が集まるだけではなく、その場にとどまっている様子がポイントです。」
例えば、こんな表現です。

  • 友人たちが公園にたむろしていた → 公園に集まって、その場でしばらく過ごしていた
  • 若者たちが駅前にたむろしていた → 駅前に集まって、しばらくその場にいた
  • 子どもたちが駄菓子屋の前にたむろしていた → 駄菓子屋の前に集まって、しばらくその場にいた

「つまり、"人が集まって、その場にとどまる"というのが核になるイメージです。」

B｜詳しい解説：「たむろ」の語源と使い方

① 「たむろ」の語源と意味

「たむろ」は、漢字で「屯する」と書きます。
「屯」には、人が集まるという意味があります。
もともとは、軍隊が駐屯するという意味で使われていました。
そこから、人が集まってその場にとどまるという意味になったんです。

② 「たむろ」の使い方とニュアンス

  • 特に目的がなく、だらだらと集まっている様子を表すことが多い
  • ただ集まるだけではなく、しばらくその場にとどまる様子を表す
  • 悪い印象で使われることもあるが、必ずしも悪い意味だけではない

「先輩、"たむろ"は、悪い意味で使われることが多い言葉です。でも、親しい仲間が集まっている場合にも使うんですよ。」

③ 「たむろ」と「集まる」の違い

言葉核となる意味違い
たむろ複数人が集まって、その場にとどまるその場に留まっている様子に注目
集まる複数人が一か所に集まる集まる行為そのものに注目

「先輩、"たむろ"は、集まるだけでなく、その場にとどまっている様子に注目する言葉です。"集まる"は、集まる行為そのものに注目する言葉です。」

D｜具体例：日常でどう使う？

例文①：公園

「友人たちが公園にたむろしていた。」
→ 友人たちが公園に集まって、その場でしばらく過ごしていた。

例文②：駅前

「若者たちが駅前にたむろして、通行人の邪魔になっていた。」
→ 若者たちが駅前に集まって、しばらくその場にいて、通行人の邪魔になっていた。

例文③：駄菓子屋

「子どもたちが駄菓子屋の前にたむろして、お菓子を食べていた。」
→ 子どもたちが駄菓子屋の前に集まって、しばらくその場にいて、お菓子を食べていた。

類義語とのニュアンスの違い

言葉核となるイメージ
集まる複数人が一か所に集まる
群がる多くの人が一か所に集まる
溜まる人が集まって、その場にとどまる
屯するたむろと同じ意味
居座るその場に長く居続ける

「先輩、"たむろ"は、複数人が集まってその場にとどまる様子を表す言葉です。"集まる"は集まる行為そのもの、"群がる"は多くの人が集まる様子、"溜まる"は人が集まってその場にとどまる様子を表します。」
