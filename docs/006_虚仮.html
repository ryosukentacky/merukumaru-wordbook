006｜虚仮（こけ）

読み方：こけ｜名詞｜仏教由来の言葉

A｜要点：まず意味をつかみましょう

先輩、『虚仮』は、愚かなこと、ばかげていること、あるいは偽りや見せかけを意味する言葉です。
ただし、日常会話では『虚仮』だけで使うよりも、『虚仮にする』『虚仮にされる』という表現で登場することが多いんですよ。
例えば、こんな文章です。

  • 「人を虚仮にするな」
  • 「彼は周囲の人間を虚仮にしている」
  • 「あんな態度を取られて、虚仮にされた気分だ」

これらは、人をばかにする、見下す、軽く扱うという意味です。
先輩、まずは『虚仮にする＝人をばかにする』と覚えてください。

B｜詳しい解説：なぜ「虚仮」が「ばかにする」という意味になるのか

先輩、少し漢字に注目してみましょう。
「虚」は、実体がないことや、うそ・偽りを表します。
「仮」は、仮のもの、真実ではないものを表します。
仏教では「虚仮」は、真実ではないこと、偽りであることを意味する言葉として使われてきました。
そこから、愚かなことや、愚かな人を指す意味も生まれたんです。
では、誰かを『虚仮にする』とはどういうことでしょう？
相手を愚かな人間として扱い、ばかにするということですね。

虚仮＝偽り・愚かなこと → 相手を愚かな人間として扱う → 相手を軽んじ、ばかにする → 虚仮にする

ここで注意です。『虚仮』という言葉そのものと、『虚仮にする』という慣用表現は、分けて覚えてくださいね。

C｜イメージ理解：場面で覚えましょう

先輩、職場でこんな場面を想像してください。
新人が一生懸命考えて改善案を出しました。ところが、先輩社員がその内容をまともに聞こうともせず、鼻で笑って『そんなことも分からないのか』と言い放つんです。
どうでしょう。単に意見に反対しているのではありませんよね。
そうです。相手を対等な人間として扱わず、見下しているんです。
これが『人を虚仮にする』という感覚ですよ。
先輩、画像の中央の男性に注目してください。
周囲の人たちが彼を指さして笑っていますね。
このように、人を笑いものにしたり、愚かな人間として扱ったりすることが『虚仮にする』です。
ただし、友人同士で笑い合うことがすべて『虚仮にする』になるわけではありません。相手を見下したり、ばかにしたりする意味合いが重要なんですよ。

D｜具体例：実際の使い方

例文①：職場

「彼は部下を虚仮にするような発言を繰り返した。」
→ 部下をばかにしたり、見下したりする発言を繰り返した。

例文②：日常生活

「人を虚仮にするのもいい加減にしろ。」
→ 人をばかにするのはもうやめろ。

例文③：人間関係

「親友に嘘をつかれ、虚仮にされた気分だった。」
→ 親友から軽く扱われ、ばかにされたように感じた。

先輩、特に『人を虚仮にするな』という表現は覚えておいてください。強い抗議や怒りを表すときに使われます。

類義語とのニュアンスの違い

言葉核となるイメージ
虚仮にする相手を愚かだと見なし、ばかにする
愚弄する相手をあざけり、侮辱する
侮る相手の能力や価値を低く見る
見下す相手を自分より劣った存在として扱う
嘲笑する相手をあざけって笑う

先輩、『虚仮にする』と『侮る』は似ていますが、少し違います。
『侮る』は、相手の実力や価値を低く見積もることです。
一方、『虚仮にする』は、相手をばかにする態度や扱いそのものに重点があります。

理解確認：3問

30秒復習

  • 意味：虚仮は偽りや愚かさを意味する
  • よく使う表現：虚仮にする
  • 虚仮にするの意味：人をばかにする、見下す
  • 使う場面：侮辱されたとき、軽く扱われたとき
  • 類義語：愚弄する、侮る、見下す
  • 注意点：単なる冗談や笑いと、相手をばかにする行為は区別する

一文記憶

「虚仮にする＝相手を愚かな人間として扱い、ばかにすること。」

先輩、『人を虚仮にするな！』という一言を覚えておけば、意味をすぐに思い出せますよ。
それと、先ほどの『剣幕』や『たじろぐ』ともつながりますね。虚仮にされた人が、ものすごい剣幕で怒り出し、その勢いに相手がたじろぐ。こうして一つの場面に結びつけると、3語をまとめて覚えられます。
