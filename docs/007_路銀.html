007｜路銀（ろぎん）

読み方：ろぎん｜品詞：名詞｜やや古風な表現

A｜要点：まず意味をつかみましょう

先輩、『路銀』とは、旅をするために必要なお金、つまり旅費や道中の費用です。
現代では『旅費』や『旅行資金』と言うことが多いですが、小説や時代劇、歴史ものの作品では『路銀』という言葉が出てきます。
例えば、こんな文章です。

  • 「旅の途中で路銀が尽きた」
  • 「故郷へ帰るための路銀を工面する」
  • 「路銀が足りず、旅を続けられなくなった」
  • 「わずかな路銀を懐に入れて旅立った」

特に重要なのは、旅先で使うお金だけでなく、旅を続けるために必要な資金という感覚です。

B｜詳しい解説：なぜ「路銀」と呼ぶのか

先輩、まず漢字を見てみましょう。
路＝道、旅の道中
銀＝銀貨、お金
昔は銀が貨幣として使われていましたから、『路銀』は文字どおり、旅の道中で使うお金という意味になるんです。
では、昔の旅人が路銀を失ったらどうなると思いますか？
宿に泊まることも、食事を買うことも難しくなりますよね。場合によっては、旅そのものを続けられなくなってしまいます。

遠くの土地へ旅に出る → 食事・宿泊・移動などにお金が必要 → 道中で使うお金を用意する → そのお金が「路銀」

ここで注意してください。『路銀』は必ず銀貨でなければならない、という意味ではありません。
昔の貨幣に由来する言葉ですが、現代の日本円でも、旅のためのお金を文学的に『路銀』と呼ぶことはできます。
ただし、普段の会話で『旅行の路銀を貯めています』と言うと、少し古風で物語めいた響きになりますね。

C｜イメージ理解：旅人を想像しましょう

先輩、江戸時代の旅人になったつもりで考えてください。
あなたは江戸から京都まで、長い道のりを歩いて旅することになりました。
腰には小さな巾着袋。中には旅のために用意したお金が入っています。
このお金で食事を買い、宿に泊まり、ときには川を渡るための費用も払うんです。
ところが、旅の途中で巾着袋を落としてしまったら……？
そうです。路銀を失って、旅を続けるのが難しくなってしまいます。
先輩、画像の巾着袋に注目してください。
この袋に入っているのは、ただの小銭ではありません。これから旅を続けるための大切なお金です。
旅人＋巾着袋＋道中のお金＝路銀。この3つを結びつけて覚えましょう。

D｜具体例：実際の使い方

例文①：旅の途中

「長旅の末、とうとう路銀が尽きてしまった。」
→ 旅を続けるためのお金がなくなってしまった。

例文②：旅立ち

「彼はわずかな路銀を携え、故郷を後にした。」
→ 少しばかりの旅費を持って故郷を出発した。

例文③：お金の準備

「旅に出るため、働いて路銀を稼いだ。」
→ 旅行に必要なお金を働いて用意した。

例文④：援助

「困っている旅人に路銀を恵んだ。」
→ 旅費に困っている旅人にお金を与えた。

先輩、『路銀が尽きる』『路銀を工面する』『路銀を稼ぐ』という組み合わせは、特に覚えておくと便利ですよ。

類義語とのニュアンスの違い

言葉核となるイメージ
路銀旅の道中に必要なお金。古風な表現
旅費旅行にかかる費用全般
路用（ろよう）旅の道中に必要な費用。古風な表現
旅銭（たびせん）旅のために持つお金
軍資金ある目的を実行するための資金

先輩、『軍資金』との違いも面白いですよ。
例えば『旅行の軍資金を貯める』と言うこともありますが、これは旅行を一つの作戦に見立てた比喩的な言い方です。
一方、『路銀』は、もともと旅のためのお金を意味する言葉なんです。
