039｜杓子定規（しゃくしじょうぎ）

品詞：名詞・形容動詞｜分野：仕事・人間関係・組織・社会
意味：決まりや規則、一定の基準にこだわりすぎて、状況に応じた柔軟な対応ができないこと。

「先輩、例えば、書類の提出期限が17時だとします。」「あなたは17時1分に書類を持って行きました。」「すると、担当者はこう言います。」「『17時を過ぎていますので、一切受け付けません。』」「1分遅れただけなのに、一切の例外を認めない。」「そんなふうに、決まりや規則にこだわりすぎて、状況に応じた柔軟な対応ができないこと。それが、杓子定規（しゃくしじょうぎ）です。」

A｜要点：まず意味をつかみましょう

① 規則や一定の基準にこだわりすぎること
決まりや規則、一定の基準にこだわりすぎて、柔軟な対応ができないことです。
② 状況や個別の事情を考慮しないこと
個別の事情や状況を考慮せず、一律に対応することです。
③ 柔軟性に欠ける対応のこと
状況に応じて柔軟に判断することができない対応のことです。
④ 杓子定規な対応は、必ずしも悪いわけではない
規則を守ること自体は大切です。問題は、規則を守ることが目的になってしまい、本来の目的を見失うことです。

代表表現：杓子定規な対応：規則にこだわりすぎて、柔軟な対応ができないこと／杓子定規に物事を考える：規則や基準にこだわりすぎて、柔軟に考えることができないこと／杓子定規な規則：状況を考慮しない、一律の規則

③ 手段と目的が逆転してしまう

本来の考え方：目的を達成する → 適切な規則や手順を用いる → 状況に応じて適切に判断する
杓子定規な考え方：規則を守ることが目的になる → 状況や事情を考慮しない → 本来の目的を見失う
「先輩、本来、規則や手順は、目的を達成するための手段です。」「しかし、杓子定規な考え方では、規則を守ること自体が目的になってしまい、本来の目的を見失ってしまうんです。」

④ 真面目さと杓子定規の違い

「先輩、真面目さと杓子定規は、似ているようで異なります。」「真面目な人は、規則を尊重しながらも、状況に応じて柔軟に対応できます。」「一方、杓子定規な人は、規則を絶対視し、状況に応じた対応ができません。」

⑤ どこから杓子定規になるのか？

ChatGPT側には、スライダー付きの概念モデル「規則への向き合い方を理解する概念モデル」があります。バーのラベルは左「規則の軽視」／中央「適切な判断」／右「杓子定規」で、初期状態は値2「原則を守った柔軟な対応」です。全5状態は次のとおりです。

  • 値0「規則の軽視」— 考え方「決まりを無視し、自分の都合だけで判断する。」／具体例「必要な承認を受けずに経費を処理する。」
  • 値1「場当たり的な対応」— 考え方「状況に合わせて対応するが、判断基準が一貫していない。」／具体例「親しい社員だけに例外を認める。」
  • 値2「原則を守った柔軟な対応」（初期状態）— 考え方「規則の目的を理解し、許された範囲で状況に応じて判断する。」／具体例「例外処理が可能か責任者に確認し、適切に対応する。」
  • 値3「形式への過度なこだわり」— 考え方「個別の事情を考慮できるにもかかわらず、従来の方法に固執する。」／具体例「改善できる手順を、前例がないという理由だけで拒否する。」
  • 値4「杓子定規」— 考え方「規則や形式を絶対視し、本来の目的や個別の事情を考慮しない。」／具体例「例外規定が存在していても、一律に対応を拒否する。」

注記：「なお、このスライダーは理解のための概念モデルであり、人物の性格を測定する正式な尺度ではありません。」

D｜具体例：実際の使い方

例文①：書類の提出

「書類の提出期限を1分過ぎただけで、一切受け付けてもらえなかった。杓子定規な対応だ。」
→ 1分遅れただけなのに、一切の例外を認めない対応は、杓子定規だという意味です。

例文②：経費の精算

「経費の精算で、領収書の日付が1日違うだけで却下された。杓子定規だ。」
→ 領収書の日付が1日違うだけで却下するのは、杓子定規だという意味です。

例文③：会議への参加

「会議への参加を、役職だけで決めるのは杓子定規だ。」
→ 会議への参加を役職だけで決めるのは、状況を考慮しない杓子定規な対応だという意味です。

例文④：クレーム対応

「クレームに対して、マニュアル通りの対応しかしないのは杓子定規だ。」
→ クレームに対してマニュアル通りの対応しかしないのは、杓子定規だという意味です。

例文⑤：社内手続き

「社内の手続きが杓子定規で、融通が利かない。」
→ 社内の手続きが規則にこだわりすぎて、融通が利かないという意味です。

例文⑥：日常

「杓子定規に物事を考えるのはやめよう。」
→ 規則や基準にこだわりすぎて、柔軟に考えることができないのはやめよう、という意味です。

実務における具体例：申請書類の提出期限｜1分過ぎただけで、一切受け付けない／経費の精算｜領収書の日付が1日違うだけで却下する／会議への参加｜役職だけで参加者を決める／クレーム対応｜マニュアル通りの対応しかしない／社内手続き｜前例がないという理由だけで、新しい提案を拒否する

① 融通が利かない（ゆうずうがきかない）：状況に応じて柔軟に対応できないこと。杓子定規とほぼ同じ意味で使われる。
② 四角四面（しかくしめん）：融通が利かず、堅苦しいこと。杓子定規と似た意味で使われる。
③ 頑固（がんこ）：自分の考えを曲げないこと。杓子定規よりも、性格そのものを指す。
