# 010｜忙殺（ぼうさつ）

読み方：ぼうさつ｜品詞：名詞・サ変動詞｜よく使う形：忙殺される

## A｜要点：まず意味をつかみましょう

先輩、『忙殺』とは、仕事や用事などに追われて、ほかのことをする余裕がなくなるほど忙しいことです。
単に『忙しい』と言うよりも、ずっと切迫した状態を表すんですよ。
例えば、こんな表現です。
- 「日々の業務に忙殺される」
- 「大量の書類整理に忙殺された」
- 「仕事に忙殺され、家族と過ごす時間がない」
- 「目先の対応に忙殺され、将来の計画を立てられない」

先輩、ここで覚えてほしいのは、やるべきことに追われて、自分の時間や心の余裕を奪われているという感覚です。
ただ仕事量が多いだけではなく、その仕事に振り回されている印象があるんです。

## B｜詳しい解説：なぜ「忙しい」ではなく「忙殺」なのか

先輩、まず漢字を見てみましょう。
忙＝忙しい、用事に追われる
殺＝勢いをそぐ、働きを失わせるほど強く作用する
もちろん、『忙殺』は実際に誰かが殺されるという意味ではありません。『殺』を使うことで、忙しさが極限に達しているような強い表現になっているんです。
では、仕事の場面を考えてみましょう。
朝から銀行明細を確認して、資料と照合して、不明点を調べて、上司から急な依頼も入ってくるとします。
一つの仕事が終わる前に次の仕事が入ってきて、気づけば夕方。明日の準備も業務改善もできませんでした。
これは、単に忙しいだけでなく、目の前の業務に忙殺されている状態と言えますね。

```text
仕事や用事が次々に発生する → 処理するだけで時間が埋まる → 休息や別のことに使う余裕がなくなる → 目の前の仕事に振り回される → 忙殺される
```

ただし、先輩。『忙殺される』は、必ずしも仕事が嫌いだという意味ではありません。
好きな仕事でも、次から次へと作業が発生して、ほかのことに手が回らなくなれば使えるんです。
また、忙殺される対象は仕事に限りません。育児、家事、受験準備、引っ越しの手続きなどにも使えますよ。

## C｜イメージ理解：場面で覚えましょう

先輩、ある会社員の一日を想像してください。
朝9時。机には未処理の書類が山積みです。
書類を一枚処理したところで電話が鳴ります。電話を終えると、今度はメールが10件。さらに上司から急ぎの資料作成を頼まれました。
時計を見ると、もう夕方6時です。
本当は業務を改善する方法も考えたかったのに、今日も目の前の仕事だけで一日が終わってしまいました。
このように、次々に発生する仕事に追われ、ほかのことを考える余裕さえなくなる状態が『忙殺』なんです。
先輩、画像の中央の男性を見てください。まだ目の前の仕事が終わっていないのに、周囲から次々と仕事を頼まれていますね。
この状況では、目の前の作業をこなすだけで精いっぱいです。
仕事が多い → 対応に追われる → 余裕がなくなる。この流れを思い浮かべれば、『忙殺』の意味を忘れにくくなりますよ。

## D｜具体例：実際の使い方

### 例文①：職場
「月末の経理処理に忙殺され、昼食を取る時間もなかった。」
→ 経理処理が非常に忙しく、ほかのことをする余裕がなかった。

### 例文②：業務改善
「日々の雑務に忙殺され、業務改善に取り組めていない。」
→ 目先の作業に追われ、長期的な改善を考える時間がない。

### 例文③：日常生活
「引っ越しの準備に忙殺され、友人への連絡を忘れていた。」
→ 引っ越しの準備が忙しすぎて、ほかのことに注意を向けられなかった。

### 例文④：仕事と生活
「仕事に忙殺される毎日から抜け出したい。」
→ 仕事に追われ続け、自由な時間がほとんどない生活を変えたい。

先輩、『忙殺される』は、何に追われているのかを前に置くと自然です。
『仕事に忙殺される』『家事に忙殺される』『対応に忙殺される』という形ですね。

## 類義語とのニュアンスの違い

| 言葉 | 核となるイメージ |
|---|---|
| 忙殺 | 忙しさに追われ、余裕を失う |
| 多忙 | 仕事や用事が多く、忙しい |
| 繁忙（はんぼう） | 業務が多く、非常に忙しい |
| 奔走（ほんそう） | 目的のためにあちこち動き回る |
| てんてこ舞い | 忙しくて慌てふためく |
| 追われる | やるべきことに時間や行動を支配される |

先輩、特に『多忙』と『忙殺』の違いは大切です。
『多忙』は、単純に仕事や用事が多い状態を表します。
一方、『忙殺』は、忙しさによってほかのことをする余裕がなくなっている点を強調するんです。
また、『奔走』は忙しく動き回ることですが、必ずしも余裕を失っているとは限りません。目標に向かって積極的に行動している場合にも使います。

## 一文記憶

「忙殺＝仕事や用事に追われ、ほかのことをする余裕がなくなるほど忙しいこと。」

先輩、今日の画像にあった、書類に囲まれて次々と仕事を頼まれる会社員を思い出してください。
忙しいというだけではなく、自分の時間も、次のことを考える余裕もなくなっている。そこが『忙殺』の核心なんです。
そして、先ほど学んだ『堆積』ともつなげられますね。仕事が次々と堆積し、その処理に忙殺される。この一文で、二つの言葉をまとめて覚えておきましょう。
