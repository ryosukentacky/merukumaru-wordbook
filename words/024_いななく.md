# 024｜いななく（嘶く）

品詞：動詞｜分野：動物・自然描写・文学
意味：馬が「ヒヒーン」と高い声で鳴くこと。

先輩、「いななく」は、主に馬の鳴き声を表す言葉なんです。例えば、牧場で一頭の馬が遠くにいる仲間に気づいたとします。馬は首を持ち上げ、大きく口を開いて、「ヒヒヒーン！」と鳴きました。このように、馬が高く響く声で鳴くことを「いななく」と言います。

## A｜要点

① 主に馬の鳴き声を表す
犬なら「吠える」、猫なら「鳴く」、馬なら「いななく」というように、動物の種類に応じた特徴的な表現です。
② 高く響く声をイメージする
馬が首を上げて「ヒヒーン」と鳴くような、よく通る声です。
③ 文学的な表現としても使われる
日常会話では「馬が鳴く」と言うことが多いですが、小説や詩では「馬がいななく」という表現が使われます。代表的な言い方は、「馬がいななく」「軍馬がいななく」「馬のいななき」です。

## B｜詳しい解説

### ① 「いななく」と「鳴く」の違い
先輩、「鳴く」はさまざまな動物に使える一般的な言葉です。例えば、「鳥が鳴く」「猫が鳴く」「馬が鳴く」どれも自然ですよね。一方、「いななく」は、特に馬の鳴き声を表します。「馬が鳴いた」よりも「馬がいなないた」の方が、馬特有の高い声が響く情景を鮮明に伝えられるんです。

### ② 馬はなぜいななくのか？
馬がいななく理由は一つではありません。仲間と連絡を取るとき、離れた仲間を呼ぶとき、興奮したときなど、さまざまな状況で声を出します。例えば、群れから離れた馬が、遠くにいる仲間に向かって鳴くことがあります。この場合、声は仲間とのコミュニケーションの一つなんです。ただし、鳴き声だけで馬の感情を正確に判断できるわけではありません。耳の向きや姿勢、周囲の状況なども重要になります。

### ③ 漢字の「嘶く」
「いななく」は漢字で「嘶く」と書きます。この漢字は日常ではあまり見かけませんが、小説や歴史の文章などに登場します。また、「嘶き（いななき）」という名詞形もあります。例：「遠くから馬の嘶きが聞こえた。」先輩、漢字は難しいので、まずは「いななく＝馬がヒヒーンと鳴く」と覚えれば十分ですよ。

## C｜イメージ理解

先輩、戦国時代の合戦前を想像してください。まだ薄暗い早朝、武将が馬にまたがっています。周囲には鎧を着た兵士たちが並び、戦いが始まるのを待っています。そのとき、一頭の軍馬が突然首を持ち上げ、「ヒヒーン！」と高い声で鳴きました。静かな戦場に馬の声が響き渡ります。「軍馬が高らかにいなないた。」先輩、こう書くと、単に「馬が鳴いた」と書くよりも、情景に迫力が出ますよね。

## D｜具体例

### 例文①：牧場
「牧場の馬が、遠くの仲間に向かっていなないた。」
→ 馬が仲間を呼ぶように、高い声で鳴いたという意味です。

### 例文②：歴史小説
「出陣を前に、軍馬が高らかにいなないた。」
→ 戦いが始まる前、軍馬の鳴き声が響いたという描写です。

### 例文③：自然描写
「静かな草原に、馬のいななきが響き渡った。」
→ 馬の鳴き声が広い草原に響く情景を表しています。

### 例文④：物語
「馬はいななきながら、前脚を高く上げた。」
→ 馬が鳴き声を上げると同時に、前脚を持ち上げた場面です。

## 類義語・似た言葉との違い

| 言葉 | 意味・ニュアンス |
|---|---|
| いななく（嘶く） | 馬が高い声で鳴く |
| 鳴く | 動物が声を出す一般的な表現 |
| 吠える（ほえる） | 犬や猛獣などが大きな声を出す |
| 咆哮（ほうこう） | 獣などが激しくほえること |
| さえずる | 小鳥などが美しい声で鳴く |
| いななき（嘶き） | 馬の鳴き声そのものを表す名詞 |

特に重要：「いななく」と「咆哮」の違い
先輩、どちらも動物が大きな声を出す場面で使われますが、違いがあります。いななくは、馬特有の鳴き方を表します。咆哮は、ライオンなどの獣が激しくほえることを表します。「馬がいななく」は自然ですが、「小鳥がいななく」とは普通言いません。動物ごとに使う動詞が違うんですね。
