# 016｜くだを巻く（管を巻く）

慣用句・動詞｜愚痴・不平不満・酒席での振る舞い
意味：酒に酔ったときなどに、同じような愚痴や不平不満を、くどくどと繰り返し言い続けること。

先輩、「くだを巻く」は、単に愚痴を言うことではありませんよ。
例えば、飲み会で同僚が「うちの上司は本当に分かってない！」と話し始めたとします。
最初はみんな真剣に聞いていたのに、30分たっても、1時間たっても、同じ不満を繰り返している。
周囲が話題を変えようとしても、また同じ話に戻ってしまう。
そんな状態が、まさに「くだを巻く」なんです。
今回は、意味を覚えやすいように、文字や解説パネルのない場面イラストで表現します。

## A｜要点

先輩、「くだを巻く」は、不平不満や愚痴を、しつこく繰り返し言い続けることです。
特に、お酒に酔った人が同じ話を何度も蒸し返すような場面でよく使います。
ただし、必ずお酒を飲んでいる必要はありません。しらふでも、同じように愚痴を延々と繰り返していれば「くだを巻く」と表現できます。
重要なのは、単に話が長いことではなく、愚痴っぽく、くどくどと話し続けるという点ですよ。

## B｜詳しい解説

先輩、例えば職場で嫌なことがあった人が、飲み会で不満を話しているとしましょう。
「今日、上司に理不尽なことを言われたんだよ」
ここまでは普通の愚痴です。
でも、その人が何度も同じ話を繰り返し、周囲が別の話題に移ろうとしても、また上司への不満に戻ってしまう。
しかも、お酒が進むにつれて声が大きくなり、相手の話を聞かず、一方的にしゃべり続ける。
こうなると「くだを巻いている」と表現できます。
ちなみに「くだ」は、糸を巻き付けるための管を指すという説明があります。
糸を巻くときのように、同じ話をくるくると繰り返す様子に結び付けて覚えると分かりやすいですよ。ただし、語源については諸説あります。
先輩、ここで一つ質問です。
「友人が好きな映画について2時間、楽しそうに語り続けた」
これは「くだを巻く」でしょうか？
……基本的には違います。
どれだけ長く話していても、単に好きなことを熱心に話しているだけなら、「熱弁する」「語り続ける」のほうが自然です。
くどい愚痴や不満が中心にあることが、この表現の特徴なんです。

## C｜イメージ理解

先輩、居酒屋での場面を想像してください。
会社帰りの二人が飲んでいます。
一人は酔っぱらって、さっきからずっと上司への不満を言っています。
「あの上司、何にも分かってないんだよ！」
「いや、本当に分かってない！」
「だからさ、あいつは……」
聞いている友人は、もう何度も同じ話を聞かされて、すっかり疲れています。
それでも本人は話すのをやめません。
先輩、この終わりの見えない愚痴の繰り返しこそが「くだを巻く」です。
画像では話し続ける人と、うんざりしている人を描いています。ただ、画像の話題は楽しそうな雑談にも見えるので、「くだを巻く」の典型例としては、今説明した居酒屋の場面のほうが正確ですよ。

## D｜具体例

### 例① 飲み会
「部長は酔っぱらうと、決まって仕事の愚痴を言いながらくだを巻く。」
→ お酒に酔うと、仕事への不満をしつこく繰り返す。

### 例② 友人関係
「彼は失恋した話を何時間も繰り返し、友人相手にくだを巻いていた。」
→ 同じ不満や嘆きを延々と話し続けていた。

### 例③ 職場
「会議が終わった後も、彼は会社への不満を並べてくだを巻いていた。」
→ お酒を飲んでいなくても使える例です。

### 例④ 日常生活
「父は昔の苦労話になると、いつもくだを巻き始める。」
→ 苦労話に不平不満が混じり、くどくどと繰り返される様子です。

## 類義語・似た言葉との違い

| 言葉 | 意味・ニュアンス |
|---|---|
| くだを巻く | 酔って愚痴や不満をくどくどと繰り返す |
| 愚痴をこぼす | 不満や弱音を口に出す。繰り返しとは限らない |
| ぼやく | 小声や独り言のように不満を言う |
| 小言を言う | 相手の欠点や行動について細かく注意する |
| 絡む（からむ） | 相手にしつこく言い寄ったり、面倒な言動をする |
| くどくど言う | 同じことをしつこく繰り返す。愚痴以外にも使える |

先輩、「愚痴をこぼす」と「くだを巻く」の違いが重要です。
「今日は仕事で嫌なことがあった」と一度だけ話すなら、愚痴をこぼす。
でも、その話を何度も繰り返し、相手が困っているのに延々と続けるなら、くだを巻く。
つまり、不満の内容だけでなく、話し方のしつこさまで含んでいるんです。
