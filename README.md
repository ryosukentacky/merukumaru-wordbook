- 054 そぞろ のQ3は、ChatGPT側の表示で正解Cと解説文が食い違っています。表示のまま収め、ファイル内に注記しています。
- ChatGPT側の表示は、同じ項目でも開くたびに異なる版が出ることがあります。本書には各ファイルに取得日時を注記した時点のライブ表示を収めています。
